### PhaserJS (projetos pessoais)

É minha principal ferramenta de desenvolvimento de jogos. Desenvolvi um MMORPG completo inspirado em Pokémon, de código aberto, com um sistema avançado de scripts e uma linguagem de scripting própria, com recursos semelhantes aos do RPG Maker.

A longo prazo, pretendo transformar o jogo em um framework ou engine para desenvolvimento de jogos (MMO)RPG, com templates para jogos por turnos e de ação, tanto single-player quanto multiplayer.

O projeto também contará com uma linguagem visual de scripts baseada em JSON, inspirada no Blueprint da Unreal Engine, no Construct, no GDevelop e em outras ferramentas de programação visual.

A engine terá recursos próprios para criação de arte, utilizando coleções de assets LPC do OpenGameArt e geração automatizada de spritesheets para personagens. Também contará com um editor visual de interfaces (UI Builder).

Como um dos principais diferenciais, pretendo integrar recursos de IA para gerar jogos a partir de prompts, incluindo sprites, sons, histórias e outros elementos.

A longo prazo, quero desenvolver uma arquitetura full stack que permita criar jogos MMO utilizando o mesmo código tanto no cliente quanto no servidor, seguindo uma proposta semelhante à que o Next.js e o Nuxt.js trouxeram para os ecossistemas React e Vue.

### Jogos de cassino e apostas

Tenho boa experiência no desenvolvimento de jogos de cassino para a web, utilizando PhaserJS, PixiJS, Canvas e WebGL.

Trabalhei presencialmente em um estúdio de desenvolvimento de videobingo para cassino, onde desenvolvi e mantive um framework baseado em PhaserJS para gerenciar templates de jogos. Também criei uma ferramenta de depuração com interface gráfica para facilitar o desenvolvimento e a manutenção, propus melhorias de engenharia e otimizações para comportamentos específicos dos jogos e desenvolvi scripts em Python para automatizar tarefas relacionadas a padrões gráficos utilizados pela equipe de arte.

Também desenvolvi jogos multiplayer online para empresas do setor de apostas.

Desenvolvi do zero um jogo de damas multiplayer online para uma empresa de apostas, utilizando PhaserJS. O projeto contava com interação entre jogadores em tempo real, sistemas de salas e canais, eventos de rede, WebSockets, matchmaking e um servidor autoritativo. A arquitetura proprietária foi organizada com base no padrão Entity-Rule-Manager, incluindo um sistema de eventos bem estruturado para controlar o loop e o fluxo de execução do jogo.

Desenvolvi também um jogo de Blackjack para cassino utilizando PixiJS, com uma arquitetura robusta e organizada, priorizando a legibilidade do código e a facilidade de manutenção a longo prazo.

Criei ainda um minigame de cara ou coroa para uma coleção de jogos secundários de uma empresa de jogos NFT, utilizando PhaserJS.

Na FBM Brasil, trabalhei presencialmente com C e C++ em sistemas embarcados para máquinas de videobingo de cassino, experiência na qual aprofundei meus conhecimentos em diversos recursos da linguagem C++.
